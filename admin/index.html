Generate Token on GitHub

GitHub Token Kaise Banaye? (1 Minute Guide)

  1. Upar diye gaye "Generate Token on GitHub" button par click karein.
  2. GitHub open hoga. Waha Note: (e.g. Portfolio Admin) dalein aur Expiration me "No expiration" ya "90 days" select karein.
  3. Select scopes me repo (Full control of private/public repositories) checkbox tick karein.
  4. Page ke bottom me "Generate token" green button dabayein.
  5. Token copy karke yaha GitHub Personal Access Token box me paste karein aur "Save GitHub Settings" dabayein.

✨ Iske baad jab bhi aap Portfolio Admin me koi bhi change karenge aur "Save to GitHub" click karenge, GitHub repository me directly commit ho jayega!
